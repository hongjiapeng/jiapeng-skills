# Naming Conventions

- Use numbered top-level folders for stable ordering: `00_Inbox`, `10_Work`, `20_Personal`.
- Use English, short, no-space paths for code and tools.
- Use `YYYY-MM-DD_Location_Topic` for shoots and dated media projects.
- Avoid symbols that cause quoting or shell issues: `&`, `%`, `#`, `?`, `*`, `<`, `>`, `|`.
- Keep temporary folders visibly disposable: `90_Temp`, `Sandbox`, `Rejects`.
