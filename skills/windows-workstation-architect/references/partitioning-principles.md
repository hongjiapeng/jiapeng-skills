# Partitioning Principles

- Keep `C:\` for Windows, installed software, development tools, and system caches.
- Put active user data on `D:\` or another data drive when available.
- Do not create many partitions only for aesthetics.
- Prefer fewer, clear roots over many drive letters.
- Do not recommend formatting, repartitioning, deleting volumes, or resizing partitions as part of v1.
- If the user has only `C:\`, recommend a folder structure under a safe user-controlled data root, not system directories.
