# Work Personal Separation

- Company documents belong in company-approved storage.
- Company code belongs in company-approved Git remotes and local work folders.
- Personal projects belong in personal folders and personal repositories.
- Treat `Work` as company or professional responsibility, not all productive personal activity.
- Keep actual code repositories in `30_Code`; use `30_Code\Work` for company code and `30_Code\Personal` for personal code.
- Use `10_Work` for company work documents, meetings, reports, references, and non-repository project material.
- Do not mix company confidential files with personal cloud sync.
- On mixed-use PCs, make boundaries visible in names and sync policies.
- When policy is unknown, ask or choose the most restrictive assumption.
