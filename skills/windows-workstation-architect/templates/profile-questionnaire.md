# Windows Workstation Profile Questionnaire

## Core Questions

Answer only what you know. The first plan can be conservative.

1. Is this a personal PC, company PC, or mixed work/personal PC?
2. What do you mainly use it for? Choose any: office documents, software development, design/UI/assets, photography, video editing, learning/notes, finance/contracts/identity, gaming, multi-PC sync.
3. What drives or storage do you currently have? For example: only `C:\`, `C:\` plus `D:\`, external hard drive, NAS.
4. What sync or backup tools do you use? For example: OneDrive, iCloud, NAS, external drive, Git, company SharePoint.
5. Do you have company confidential files or sensitive personal files that require isolation or encryption?

## Optional Details

- Approximate size of documents, code, photos, videos, and archives.
- Whether the PC is managed by a company.
- Whether you travel with the PC.
- Whether multiple users share the PC.
- Whether old files need migration planning later.
