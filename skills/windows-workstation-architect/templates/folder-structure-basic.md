# Basic Folder Structure

```text
D:\
├─ 00_Inbox
├─ 10_Work
├─ 20_Personal
├─ 30_Code
├─ 40_Media
├─ 50_Archive
└─ 90_Temp
```

- `00_Inbox`: temporary intake
- `10_Work`: company or professional work documents
- `20_Personal`: personal material
- `30_Code`: code and scripts
- `40_Media`: photos, videos, design files, exports
- `50_Archive`: completed and historical material
- `90_Temp`: disposable files

`Work` means company or professional responsibility. Personal projects, side products, learning, and hobbies should use `20_Personal` or `30_Code\Personal`.
