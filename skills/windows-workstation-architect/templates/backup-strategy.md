# Backup Strategy

| Type | Recommended source of truth | Sync | Backup |
| --- | --- | --- | --- |
| Documents | Work or personal document folder | Cloud sync when policy allows | Periodic offline copy |
| Code | Git remote | Git fetch/push/pull | Remote repo plus important local config backup |
| Photos | Local media drive | Selected exports only | Offline drive or NAS |
| Videos | Local media drive | Selected exports only | Offline drive or NAS |
| Identity files | Encrypted private folder | Avoid broad sync | Encrypted offline copy |
| Contracts | Encrypted private folder | Limited, deliberate sync | Encrypted offline copy |
| Company files | Company-approved system | Company OneDrive/SharePoint/internal storage | Follow company policy |
| Temporary files | `90_Temp` | None | None |
| Archives | `50_Archive` | Optional | Offline copy and periodic check |

Sync keeps devices convenient. Backup protects against deletion, corruption, account loss, and hardware failure.
