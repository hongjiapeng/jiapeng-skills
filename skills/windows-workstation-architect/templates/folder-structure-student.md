# Student And Learning Folder Structure

```text
D:\20_Personal\Learning
├─ Courses
├─ Notes
├─ Books
├─ Papers
├─ Assignments
└─ Exams
```

Rules:

- Keep courses, notes, books, papers, assignments, and exams separate.
- Keep note attachments organized.
- Back up important learning material.

## Photography Learning

Use this for learning materials about photography, not for original photo or video projects:

```text
D:\20_Personal\Learning\Photography
├─ Courses
├─ Notes
├─ Books
├─ References
├─ Practice
└─ Attachments
```

- Put photography courses, tutorials, lesson videos, books, notes, and practice assignments here.
- Put original photos, videos, Lightroom catalogs, edits, and exports under `D:\40_Media`.
