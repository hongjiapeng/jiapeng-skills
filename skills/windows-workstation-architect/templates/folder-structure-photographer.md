# Photography And Video Folder Structure

```text
D:\40_Media
├─ Photos
│  ├─ 2026
│  └─ Lightroom
├─ Videos
│  ├─ 2026
│  └─ Projects
├─ Exports
└─ Assets
```

Shoot folder pattern:

```text
2026-07-04_Shanghai_StreetPortrait
├─ 00_Raw
├─ 10_Selects
├─ 20_Edit
├─ 30_Export
└─ 90_Rejects
```

Rules:

- Separate RAW, selects, edits, exports, and rejects.
- Keep Lightroom catalogs separate from originals.
- Back up original media outside the workstation.
