# Developer Folder Structure

```text
D:\30_Code
├─ Work
│  └─ CompanyName
├─ Personal
│  ├─ Products
│  ├─ OpenSource
│  └─ Labs
├─ Forks
├─ Tools
└─ Sandbox
```

Rules:

- Keep company and personal code isolated.
- Put company repositories under `D:\30_Code\Work\CompanyName`.
- Put personal products, open source work, and experiments under `D:\30_Code\Personal`.
- Keep `D:\10_Work` for company documents and project material, not Git repositories.
- Use Git as the source of truth.
- Do not sync `.git` repositories through consumer cloud folders.
- Prefer short English paths.
